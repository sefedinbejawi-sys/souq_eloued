# لوحة تحكم سوق الوادي — Professional Marketplace

## الوصول
`/admin` متاح فقط لـ `admin` أو `moderator`. حماية الواجهة مدعومة بسياسات RLS داخل Supabase.

## إدارة الإعلانات
- مراجعة الإعلانات الجديدة قبل نشرها.
- قبول/رفض/أرشفة/حذف حسب الصلاحية.
- مشاهدة البائع، التصنيف، البلدية، السعر، الصور وسبب الرفض.
- الإعلانات المنشورة تبقى غير قابلة للتلاعب من البائع في حالة الاعتماد؛ التعديل الجوهري يعيد الإعلان للمراجعة.

## لوحة البائع
`/my-listings`
- إجمالي الإعلانات.
- قيد المراجعة.
- المنشورة.
- المباعة.
- عدد المشاهدات.
- وضع الإعلان كمباع.
- أرشفة الإعلان.
- زر **إعادة نشر لأسبوع** يظهر بعد 7 أيام من آخر نشر إذا كان الإعلان ما زال منشوراً وغير مباع.

إعادة النشر لا تعتمد على JavaScript فقط؛ يوجد RPC آمن في قاعدة البيانات باسم `republish_listing` يتحقق من صاحب الإعلان والحالة ومرور 7 أيام.

## الحسابات
يمكن إنشاء الحساب كـ:
- مشتري
- بائع
- مشتري وبائع

Google OAuth والبريد الإلكتروني يعملان عبر Supabase Auth. استعادة كلمة المرور تستخدم:
`/auth/reset`

## أول مدير
بعد إنشاء الحساب، نفّذ في Supabase SQL Editor:
```sql
update public.profiles
set role='admin', is_banned=false, updated_at=now()
where id=(select id from auth.users where email='admin@example.com');
```

## إضافة مزايا مستقبلية
قاعدة المشروع مصممة للتوسع دون إعادة بناء المصادقة أو الإعلانات، ويمكن لاحقاً إضافة:
- تصنيفات وبلدان ومدن جديدة.
- عملات متعددة.
- متاجر وحسابات تجارية موثقة.
- رسائل داخلية بين المشتري والبائع.
- عروض وأسعار تفاوضية.
- دفع إلكتروني وشحن.
- اشتراكات وإعلانات مميزة.
- لغات متعددة.
- نظام بلاغات ومراجعات وتقييمات.
- تحليلات متقدمة.

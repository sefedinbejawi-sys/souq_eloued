# لوحة تحكم سوق الوادي

## الوصول

توجد لوحة التحكم على المسار `/admin`. لا يمكن الوصول إليها إلا للمستخدم الذي يملك `role = 'admin'` داخل `public.profiles`، وتتحقق الواجهة من الصلاحية كما تحميها سياسات RLS في Supabase.

## تفعيل أول مدير

بعد إنشاء حساب المدير من واجهة الموقع، نفّذ الاستعلام التالي في **Supabase SQL Editor** مع استبدال البريد الإلكتروني بالبريد المستخدم في الحساب:

```sql
update public.profiles
set role = 'admin', is_banned = false, updated_at = now()
where id = (
  select id
  from auth.users
  where email = 'admin@example.com'
);
```

بعد ذلك سجّل الخروج ثم الدخول من جديد، وافتح:

```text
https://souq.myeloued.com/admin
```

## صلاحيات اللوحة

تسمح اللوحة للمدير بعرض الإعلانات قيد المراجعة، قبول الإعلان ونشره، رفضه وأرشفته، حذفه نهائياً، وعرض المستخدمين وحظر الحساب أو إلغاء حظره. الإعلانات الجديدة تُحفظ بحالة `draft` ولا تظهر للجمهور حتى يوافق عليها المدير.

## الحماية

يُمنع المستخدم المحظور من نشر الإعلانات ورفع الصور، ولا تعتمد الحماية على الواجهة فقط؛ إذ تطبقها دوال وسياسات RLS داخل قاعدة البيانات. لا تستخدم حساب `service_role` داخل الواجهة أو في المتصفح.
